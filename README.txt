Cloudflare deployment:
1. Unzip the folder.
2. In Cloudflare Workers & Pages, create a new Pages project using Direct Upload.
3. Upload the folder or ZIP.
4. No build command is required. The output directory is the project root.
5. Connect the desired custom domain after deployment.
